# House Price Prediction

## 1.1 Summary

The application provides a portal for users to perform housing price predictions and real estate market analysis. It specifically includes two applications: Valuation and Market Analysis.

## 1.2 Details

### 1.2.1 File Structure

- house-price-marking-service: Provide capabilities related to real estate market analysis
- house-price-prediction-service: Provide housing price prediction capabilities
- house-price-prediction-web: Front-end interactive page
- house-price-prediction-model: Real Estate Price Prediction Model Project

### 1.2.2 Use of Technology Stack 

- Frontend: Next.Js, React, Next.Js-Router, Echart、Tailwind CSS
- Backend:
  - Fast-API (house-price-prediction-service Python-3.12)
  - SpringBoot (house-price-marketing-service Java-21)
- Database: Redis, MySQL
- ML: Scikit-learn
