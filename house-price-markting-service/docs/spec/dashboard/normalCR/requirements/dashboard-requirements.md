# Analysis-dashboard 

## 1. Summary

针对房屋数据进行 Dashboard 展示

## 1.2 Details

### 1.2.1 数据格式

提供的数据格式如下

| **id** | **square_footage** | **bedrooms** | **bathrooms** | **year_built** | **lot_size** | **distance_to_city_center** | **school_rating** | **price** |
| ------ | ------------------ | ------------ | ------------- | -------------- | ------------ | --------------------------- | ----------------- | --------- |
| **1**  | 1250               | 2            | 1             | 1985           | 5200         | 3.2                         | 7.1               | 185000    |
| **2**  | 1850               | 3            | 2             | 1998           | 7500         | 5.6                         | 8.2               | 265000    |
| **3**  | 1420               | 3            | 2             | 1992           | 6800         | 2.8                         | 6.9               | 210000    |


### 1.2.2 数据筛选

用户可针对数据中的所有字段进行区间筛选

### 1.2.3 Dashboard 视图

Dashboard 包含 4 个数值数据和 3 个数据图表

数值数据:

1. 数据总量 total records: 表示数据总量 (若有筛选则为筛选后)
2. 平均价格 avg-price: 价格的平均值 (若有筛选则为筛选后)
3. 房价中位数 Median price: 房屋价格的中位数 (若有筛选则为筛选后)
4. 平均每平方英尺价格 avg per Sq.Ft: 平均的房屋每平方英尺价格 (若有筛选则为筛选后)

图标数据:

1. 数据的数量与价格分布, x 轴为 价格区间, y 轴为 该价格区间的房屋数量, 柱状图
2. 价格与面积的散点图
3. 价格与建造年份的趋势图 (折线)
