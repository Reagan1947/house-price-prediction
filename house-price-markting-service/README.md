详细文档地址: [点我](http://blog.baolong.icu/SpringBoot/bq4rplc8/)

## 快速开始

1. 安装好 JDK、MySQL、Redis
2. 克隆当前项目

```git
git clone git@github.com:SilasYan/silas-boot-template.git
```

3. 执行 `sql` 下的 `silas_boot_template.sql` 文件
4. 修改 `application.yml` 文件; 或新建 `application-dev.yml` 文件
5. 启动 `SilasBootTemplateApplication.java`
