# Landing-page-requirements

## 1.1 Summary

UI/UX Figma 设计: https://www.figma.com/design/M2IiAGmNgLFwWveEkq3v5C/Untitled?node-id=0-1

## 1.2 Detail

### 1.2.1 Hading

头部区域为分布对齐, 左侧为网站 Icon, 右侧为 Service 页面入口和 Login 登录按钮。点击后分别进入 Service 页面和 Login 页面。

### 1.2.2 Matain

主体部分为渐变色背景和 Hero 信息, Hero 信息:

- Title: Efficiently predict your house price

- Describe Information: Use machine learning models to predict your property price information based on multidimensional data prediction.

底部为两个合并在一起的按钮, 一个为 Predict Now, 另一个为 Login。Predict Now 按钮点击后跳转到 House Price Valuation 应用。Login 按钮点击后跳转到 Login 页面。
