## 1.2 Detail
### 1.2.1 Home Page

应用选择门户端点包含两个子页面，左侧导航可见有 Home Page 和 Application List。

Home Page 页面包含三个区域

1. Shortcut

    快捷方式，用于快速访问 APP，其中列出了该用户可访问的 APP

2. Advice

    建议，通过卡片的形式列出了应用使用建议。

3. Recently

    Recently 展示了近期用户操作。

### 1.2.2 Application List

Application List 展示了用户可访问应用列表
