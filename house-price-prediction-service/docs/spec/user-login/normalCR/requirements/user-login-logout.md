# User-login-logout

## 1.1 Summary

该需求为实现一个简单的用户登录功能, 不需要实现用户注册。以及简单的通过 Token 的用户登录状态管理。

## 1.2 Detail

### 1.2.1 User-login

实现一个简单的用户登录端口, 并返回用户 Token 信息。登录请求仅包含用户名和密码，不包含验证码字段。可以补充其他用于管理 Token 的附加接口, Token 信息使用 Redis 进行缓存。

实现一个简单的用户信息接口, 用户信息包括
1. 用户名
2. 用户邮箱

若需要可附加额外的用户信息编辑等其他接口

### 1.2.2 User-logout

实现一个简单的用户登出接口。
