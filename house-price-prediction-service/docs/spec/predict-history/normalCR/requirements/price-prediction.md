# Price-prdiction

## 1.1 Summary

该功能主要为实现一个房价预测以及历史信息查看功能。

## 1.2 Detail

### 1.2.1 房价预测

现在系统已实现房价预测接口, 接受用户维度信息
square_footage	bedrooms	bathrooms	year_built	lot_size	distance_to_city_center	school_rating

### 1.2.2 创建房价预测实例

用户首先会点击创建房价预测, 用户可填写除了房价预测基本维度信息, 额外可填写标题和房产位置信息。用户可在填写完后点击保存。或填写完后立即点击房价预测, 再保存房价预测实例。

### 1.2.3 房价预测历史记录

需要可分页查询房价预测历史记录, 用户可以对历史记录进行再次编辑, 或删除, 或打开预测实例再次预测房价。用户可对房价预测实例的历史记录进行搜索, 每个字段均可搜索, 并包含创建和更新时间。删除为逻辑删除。
